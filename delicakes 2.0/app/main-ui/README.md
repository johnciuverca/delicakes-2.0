# DELICAKES Main UI

This folder contains the main DELICAKES frontend app.

It is built with React, TypeScript, and Vite.

## Run locally

```bash
npm run dev
```

## Scripts

```bash
npm run dev
```

Starts the local development server.

```bash
npm run build
```

Checks TypeScript and creates a production build.

```bash
npm run lint
```

Runs ESLint for the frontend app.

```bash
npm run preview
```

Serves the production build locally.
