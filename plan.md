# DELICAKES 2.0 Plan

## Goal
Rebuild the Delicakes project from scratch as a learning-first project.

## Main outcome
- one main app for home, auth, recipes, profile, about, contact
- one separate expense tracker app
- one backend API
- all using TypeScript, React, Vite, Express, Git, and GitHub

## Learning approach
- work in small tickets
- one concept at a time
- write code yourself
- learn by building
- keep notes after each step

## Phases
1. Setup and boilerplate
2. Backend hello world
3. Main frontend shell
4. Auth flow
5. Recipes feature
6. Profile and content pages
7. Expense tracker app
8. Backend integration
9. Polish and cleanup

## First steps
- create the repo structure
- create the backend folder
- create the frontend folder
- create the expense tracker folder
- create docs files for roadmap, tickets, and notes
